# Security policy

RAYS listens on the local network (Art-Net UDP 6454, Pro DJ Link, Ableton Link) and can
ask macOS for administrator rights to add a temporary IP alias for a direct cable to an
Art-Net node. If you find a way to abuse any of this, please **do not open a public issue**.
Use [GitHub private vulnerability reporting](../../security/advisories/new) instead.
You'll get an answer within a week.
